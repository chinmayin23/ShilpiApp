ShilpiApp

A digital showcase for traditional Indian stone sculptures crafted by local artisans from Karnataka.


About
ShilpiApp is an Android application that brings the rich heritage of Indian stone sculpture to your fingertips. It connects art lovers and buyers with talented artisans from Karnataka's historic villages — Shivarapatna, Belur, Halebidu, and Mysuru — who carry forward centuries-old sculpting traditions.

Features
Browse & Explore

Gallery of 10 handcrafted sculptures with search functionality
Detailed view for each sculpture with pinch-to-zoom
Heritage style stories — Hoysala, Chalukya, Dravidian, and more
AI-written descriptions for each sculpture

Inquire

WhatsApp inquiry button with Product ID for direct communication with artisans

Artist Profiles

Dedicated artist profile pages showcasing each artisan's story and work
Work-in-Progress timeline showing how sculptures are made step by step

User Access

User Login & Registration
Forgot Password support
Guest Access for browsing without an account

Admin Panel

Add, update, and delete sculpture listings
Manage artisan profiles and content

Backend

Powered by Firebase for real-time data, authentication, and storage

Getting Started
Prerequisites

Android Studio installed
Firebase account with project set up
google-services.json file (not included in repo for security)

Setup Instructions

Clone the repository

bashgit clone https://github.com/chinmayin23/ShilpiApp.git

Open in Android Studio

Open Android Studio
Click File → Open
Select the cloned ShilpiApp folder


Add Firebase configuration

Download your google-services.json from Firebase Console
Place it inside the app/ folder


Build and Run

Click the Run button in Android Studio




Security Note
The google-services.json file is excluded from this repository for security reasons.
Please set up your own Firebase project and add the configuration file locally.
